# dsh-market-plus 插件市场Plus

**病根**（社区反馈）：插件市场卡片只有名称+一句简介，想看效果得装一遍，功能重叠难挑选。

**解法**：点开任意插件 → 即时渲染该插件 GitHub **README 全文**（免安装看效果）+ 应用市场式统计条（★星数/⑂fork/最近更新/开源协议/仓库大小）+ 仓库直链。

**保留原市场全部浏览功能**：推荐 / 搜索 / 中文分类 / 热门标签 / 排序 / 收藏 / 已装 / 已发布 —— 读取同一份市场缓存（plugins-cache.json），零迁移共存，装上即用。

**隐私**：零遥测零上报；README 仅浏览器端拉取与本地缓存。

## 用法
安装后访问 `/market-plus/`，点任意卡片「📖 详情」。
